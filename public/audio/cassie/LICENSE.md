# CASSIE voice lines: licence and attribution

The `.ogg` files in this folder are the CASSIE voice lines and background track from **SCP: Secret Laboratory**
by Northwood Studios (https://scpslgame.com/), licensed under the
[Creative Commons Attribution-ShareAlike 3.0 licence](https://creativecommons.org/licenses/by-sa/3.0/legalcode).
They are unchanged except for the file names (`<n>.ogg` is the n-th line of the game's "Cassie Words" database,
`background.ogg` is CASSIE-background-std). The word list and timings in `src/cassie/words.json` come from the same database.

These files are shared under the same licence, **CC BY-SA 3.0**. This project is a fan tool and is not
affiliated with or endorsed by Northwood Studios.
